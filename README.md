## 📌 Overview

**Python-Learning-Book** is designed as a living computational textbook. Instead of reading passive syntax manuals, each topic is demonstrated inside executable Jupyter Notebooks featuring clear markdown explanations, code blocks, output visualizers, and self-testing challenges.

---

## 📚 Curriculum Breakdown

| Module / File | Description & Core Topics |
| :--- | :--- |
| **[`learning-python.ipynb`](learning-python.ipynb)** | Core Python fundamentals: Variable assignment, dynamic typing, arithmetic & logical operators, string manipulations, and conditional branching (`if`/`elif`/`else`). |
| **[`python-brocode.ipynb`](python-brocode.ipynb)** | Practical reference workbook: Iteration patterns (`for`, `while`, nested loops), collection types (lists, tuples, sets, dictionaries), list comprehensions, and built-in functions. |
| **[`Assignment.ipynb`](Assignment.ipynb)** | Problem-solving suite: Algorithm exercises, mathematical problem sets, recursive functions, and string parsing challenges. |
| **[`list.py`](list.py)** | Standalone reference script detailing Python list mutations, slicing, indexing methods, sorting algorithms, and lambda operations. |
| **[`sample.py`](sample.py)** | Scripting prototypes demonstrating functional modularity and standard library utilities. |

## 🚀 How to Run Locally

### Option 1: Using VS Code (Recommended)
1. Install [VS Code](https://code.visualstudio.com/) and the **Python** + **Jupyter** extensions.
2. Clone this repository:
   ```bash
   git clone https://github.com/Akhil-Binu/Python-Learning-Book.git
   cd Python-Learning-Book
   ```
3. Open any `.ipynb` notebook file directly in VS Code and click **Run All**.

### Option 2: Using JupyterLab / Jupyter Notebook
```bash
# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install Jupyter
pip install jupyterlab notebook

# Launch Jupyter server
jupyter notebook
```
